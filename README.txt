GLN Graphing Calculator - GitHub Pages PWA

Upload ALL files in this folder to the ROOT of the same GitHub repository that hosts your calculator.

Files:
- index.html (your calculator + PWA tags)
- manifest.json
- service-worker.js
- icon-192.png
- icon-512.png
- apple-touch-icon.png

GitHub Pages:
Settings > Pages > Deploy from a branch > main > /(root) > Save

On iPhone/iPad:
Open the GitHub Pages URL in Safari > Share > Add to Home Screen > Add.
